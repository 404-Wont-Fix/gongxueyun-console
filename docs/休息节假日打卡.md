# 休息/节假日打卡

支持三种提交类型：上班 `START`、下班 `END`、休息/节假日 `HOLIDAY`。

## 协议依据

已保存的 APK 5.41.6 反汇编：

- `analysis/blutter-5.41.6/asm/gxy_app/pages/attendance/attendance_type_widget.dart`：0x1191a5c 显示“休息/节假日”；0x1191b74 / 0x1191bac / 0x1191be8 分别选择 START / END / HOLIDAY，随后写回选定类型。
- `analysis/blutter-5.41.6/asm/gxy_app/pages/school/attendance_model.dart`：0x1182e50 比较 HOLIDAY，0x1182e70 转为“休息/节假日”。
- 新版参考仓库 `repos/tangqingfeng7__AutoCheck-in-GongXueYun/server/task_runner.py` 使用 HOLIDAY，`server/verification_sessions.py` 允许该类型。

## 本次实现范围

账号管理、总览、考勤记录提供第三个手动提交入口，补卡类型也可选休息/节假日。记录与统计显示对应名称。

仍使用现有 save/replace 接口及签名流程，type 参与签名；仅找到对应日期、HOLIDAY 类型记录才报告确认成功。验证码和本人验证规则不变。

自动排班现支持中国官方放假/调休日历：放假区间在上班时间提交一次 HOLIDAY，补班日期执行上下班；新账号默认普通日期七天执行，已有账号的星期选择保留。可关闭跟随日历，或在日历页设置单日覆盖。当天已有休息卡成功/待确认/待验证时自动调度不会再发上下班，反之亦然。详见《日历与自动排班.md》。

验证采用模拟传输，不提交真实账号；服务端是否允许某个日期休息打卡或补卡，仍受实际计划与学校规则约束。
